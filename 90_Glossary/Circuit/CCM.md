# 1. 뜻
- CCM은 Continuous Conduction Mode의 약자로 인덕터 전류가 스위칭 주기 동안 끊어지지 않는 동작이다.

# 2. 동작과 사용
- 기본 단방향 컨버터에서는 한 주기에서 인덕터 전류의 최솟값이 0보다 크다.
- 이상적인 Buck·Boost 변환비를 사용할 때 CCM 정상상태 가정을 함께 확인한다.

# 3. 예
- 부하가 충분히 큰 Buck 컨버터에서는 인덕터 전류가 주기 내내 흐를 수 있다.

# 4. 헷갈리는 점
- 전류가 경계에서 순간적으로 0에 닿는 상태와 0에 머무는 구간이 있는 [[90_Glossary/Circuit/DCM|DCM]]은 구분한다.
- 동기식 컨버터의 역전류 허용 여부는 별도의 동작 조건이다.
