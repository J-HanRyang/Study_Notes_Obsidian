# 1. 뜻
- DCM은 Discontinuous Conduction Mode의 약자로 인덕터 전류가 주기 중 0에 도달해 머무는 구간이 있는 동작이다.

# 2. 동작과 사용
- 같은 회로와 입력 조건에서도 부하가 가벼워지면 DCM으로 전환될 수 있다.
- DCM에서는 CCM에서 쓰는 단순 변환비를 그대로 적용하지 않는다.

# 3. 예
- 부하 전류가 작을 때 인덕터에 저장된 에너지가 다음 스위칭 주기 전에 모두 전달될 수 있다.

# 4. 헷갈리는 점
- 경계에서 0에 잠깐 닿기만 하면 DCM의 0 유지 구간과 다르다.
- 강제 동기 동작의 역전류는 별도로 확인한다.
