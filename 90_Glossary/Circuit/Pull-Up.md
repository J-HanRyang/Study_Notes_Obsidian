# 1. 뜻

- 출력들이 해제된 신호선을 전원 쪽으로 끌어올리는 경로.

# 2. 동작과 사용

- 저항 풀업은 LOW 때의 전류와 HIGH로 상승하는 속도 사이에서 값을 정한다.

# 3. 예

- I2C의 SDA와 SCL에는 각각 풀업 경로가 있다.
- 보드마다 저항이 있으면 병렬 합성값을 본다.

# 4. 헷갈리는 점

- 작을수록 무조건 좋은 저항이 아니다.
- Sink 전류 한계와 버스 정전용량을 함께 확인한다.
