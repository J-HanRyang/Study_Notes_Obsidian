# 1. 뜻

- 출력단이 핀을 HIGH나 LOW로 적극적으로 구동하지 않는 상태.

# 2. 동작과 사용

- 외부 핀 전압은 풀업·풀다운·다른 장치 등 연결된 회로에 따라 결정된다.

# 3. 예

- Open-Drain 트랜지스터가 OFF이면 출력 경로는 해제된다.
- 다른 장치가 LOW를 유지할 수도 있다.

# 4. 헷갈리는 점

- High-Z는 논리 1도, 입력 기능 OFF도 아니다.
- 일반 Push-Pull에 항상 High-Z 제어가 있는 것은 아니다.
