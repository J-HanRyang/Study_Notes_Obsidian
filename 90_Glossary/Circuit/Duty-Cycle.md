# 1. 뜻

- 한 주기에서 지정한 ON 상태가 차지하는 시간 비율.

# 2. 동작과 사용

- Duty Cycle은 $D=t_{ON}/T$로 계산한다.
- 스위칭 주파수 $f=1/T$와는 서로 다른 양이다.

# 3. 예

- T=10 µs, ON=4 µs이면 D=0.4=40%다.
- 같은 D에서도 주파수는 바꿀 수 있다.

# 4. 헷갈리는 점

- 반전형·비반전형에 같은 변환비를 적용하지 않는다.
- 어떤 스위치의 ON을 정의했는지도 확인한다.
