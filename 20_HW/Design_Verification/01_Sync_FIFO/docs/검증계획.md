# 기본 실습 검증 계획

| 단계 | 자극 | 확인 |
| --- | --- | --- |
| 쓰기 | wr_en=1, rd_en=0, wdata=A5 | 수락된 입력을 예상 queue에 저장 |
| 읽기 | wr_en=0, rd_en=1 | queue에서 꺼낸 A5와 실제 rdata 비교 |
| 종료 | 기존 sequence 종료 | 비교 1건, 예상 queue 잔여 0, UVM_ERROR/FATAL 0 |
| 발생 집계 | monitor가 수집한 요청 | idle/read/write/동시 요청 카운터 출력 |

현재는 깊이 4, 데이터 폭 32비트 기본 쓰기→읽기만 실행합니다. full/empty 자체 검사, 동시 요청 자동 시나리오, wrap, 중간 reset, 랜덤 회귀, assertion은 현재 기본 실습에 넣지 않았습니다. 해당 확장 코드와 이전 결과는 ../tb_extend/에 보관합니다.
