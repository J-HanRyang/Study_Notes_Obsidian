# 기본 버전 실행 결과 — 2026-10-18

사용자의 기존 driver·monitor 흐름을 복원하고 최소 scoreboard·coverage만 연결한 버전입니다. 확장 버전의 코드와 이전 실행 결과는 ../tb_extend/에 보관했습니다.

## 실행 명령

```bash
bash run.sh build
bash run.sh run
```

환경: WSL Ubuntu-24.04, Verilator 5.052, UVM 2020.3.1, UVM_NO_DPI. 기본 빌드에는 --assert와 파형 출력을 사용하지 않습니다.

## 실제 확인 결과

```text
[SCB] PUSH data=000000a5 queue_size=1
[SCB] MATCH expected=000000a5 actual=000000a5
[COV] idle=2 read=1 write=1 simultaneous=0
[SCB] writes=1 comparisons=1 remaining=0
UVM_ERROR : 0
UVM_FATAL : 0
Basic A5 write/read comparison PASS
```

- 시간 50ns에 A5 입력을 예상 queue에 저장했습니다.
- 시간 70ns에 읽은 A5와 예상값을 비교했습니다.
- 마지막 monitor 비교가 끝난 다음 75ns에 종료했습니다.
- UVM_WARNING 2건은 UVM_NO_DPI 사용 안내와 DPI 없이 component 이름 제약 검사가 생략된다는 안내입니다.
- 빌드는 완료했고 basic_build.log에서 %Warning/%Error는 없었습니다.
- 기존 agent, sequencer, 상위 sequence, write/read sequence는 보관 사본과 SHA256이 동일합니다.
- driver와 monitor는 대화에 남아 있는 사용자 작성 코드의 동작으로 복원했습니다. reset 명령, 요청 id, reset 관찰 transaction 등 확장 로직은 없습니다.

로그: logs/basic_build.log, logs/basic_run.log.

현재 확인 범위는 기본 쓰기·읽기 데이터 한 건과 요청 카운터입니다. full/empty 자체 정확성, wrap, 중간 reset, 랜덤 회귀, assertion 통과를 이 기본 버전의 결과로 표시하지 않습니다.
