## 의도적 오류 검출

bash run.sh run 1 +INJECT_MISMATCH 실행에서 첫 읽기의 비교용 예상값을 1비트 반전했습니다.

```text
[DATA] id=2 expected=000000a4 actual=000000a5
UVM_ERROR : 1
UVM_FATAL : 1
```

실행은 실패로 판정됐고 PASS 표시는 없었습니다. regression 스크립트는 이것을 검출기 self-test 성공으로 확인하여 다음을 출력했습니다.

```text
REGRESSION PASS: seeds 1/7/42 passed; intentional mismatch was detected.
```

DUT 소스 변경 없이 plusarg로 비교 값만 주입했습니다. 일반 실행에는 이 주입이 적용되지 않습니다.

## 경고·수정한 문제

- 모든 실행의 UVM_WARNING 2건은 NO_DPI_USED(해당 지원의 향후 제거 검토 안내), NO_VISIT_CHECK(DPI 정규식 없이 component 이름 제약 검사가 비활성화됨)였습니다. DUT 데이터 mismatch 경고가 아닙니다.
- 최초 FST 빌드는 lz4.h 누락으로 실패했습니다. 추가 설치 없이 사용하는 VCD로 바꾼 최종 빌드는 성공했습니다.
- 오류 주입 시 Verilator가 UVM_FATAL 종료 예약 후 다음 PASS 출력까지 수행하는 현상을 발견했습니다. 실패 분기에 return을 추가하고 실행 스크립트가 severity 집계도 검사하도록 수정했습니다. 수정된 소스로 재빌드 후 위 모든 검사를 다시 수행했습니다.
- 폭 관련 경고 두 건은 randomize() 반환값을 0과 명시적으로 비교하고 operation 값을 int로 cast하여 정리했습니다.
