# FIFO 검증 계획

기준: rtl/sync_fifo.sv, DATA_WIDTH=32 / FIFO_DEPTH=4. RTL은 변경하지 않습니다.

| 항목 | 입력·사전 상태 | 기대 결과 | 관찰·통과 기준 |
| --- | --- | --- | --- |
| 기본 순서 | A5 쓰기 후 읽기 | A5 응답 | scoreboard accepted read 비교 |
| empty read | empty=1, rd_en=1 | 읽기 거부, 포인터/출력 유지 | pre/post flags, rdata, pointer assertion |
| full write | 4개 저장 후 wr_en=1 | 쓰기 거부 | 독립 queue·pointer assertion |
| empty 동시 요청 | empty=1, wr_en=rd_en=1 | write만 수락, 기존 rdata 유지 | 독립 pre-level로 수락 계산 |
| full 동시 요청 | full=1, wr_en=rd_en=1 | read만 수락, 새 wdata 버림 | queue pop, 응답 비교, post flags |
| middle 동시 요청 | 1~3개 저장, 동시 요청 | 둘 다 수락, 순서 유지, level 유지 | pop old front / push new wdata |
| wrap | 여러 차례 4개 fill/drain | 주소 wrap 이후에도 순서 유지 | 비교 통과, write/read wrap 카운터 |
| reset | empty/middle/full에서 3클럭 reset | 포인터·rdata=0, empty=1, full=0 | queue 초기화, assertion, reset 3개 bin |
| random | 200개 요청, 고정 seed | 수락된 요청만 반영 | 1/7/42 seed 실행, 종료 drain |
| 종료 | 마지막 요청 처리 완료 | 검사 누락·대기 데이터 없음 | driver count == scoreboard last id, queue size=0 |
| 오류 검출 | 첫 읽기 비교 예상값 1비트 반전 | DATA error 및 실패 | INJECT_MISMATCH 실행 실패 확인 |
| 관찰·파형 | UVM_HIGH 또는 WAVES | 요청/수락/응답 관계 재현 | 로그와 선택적 fifo.vcd |

완료는 정상 사례의 자동 비교, 기능 bin, assertion 실행, 의도적 오류 검출 결과를 함께 봅니다. 실제 수행 결과는 실행결과.md에 기록합니다. 고급 reset 중단, 파라미터 sweep, code coverage는 범위 밖입니다.
