# 1. 발생 조건

- 입력이 수신 클록의 setup·hold 구간에서 변하면 플립플롭 출력이 안정된 논리값에 도달하는 시간이 길어질 수 있다.

# 2. 2-FF Synchronizer

- 첫 플립플롭이 비동기 입력을 받고 두 번째 플립플롭이 다음 수신 에지에서 첫 단계 출력을 샘플링한다.
- 첫 단계 출력은 두 번째 단계로만 보내고 소비 로직은 마지막 단계 출력을 사용한다.
- 두 단계 사이의 배선 지연이 길어지면 첫 단계가 안정화될 시간이 줄어든다.

# 3. MTBF 읽기

- MTBF는 동기화 실패 사이의 평균 시간을 추정한 값이다.
- 같은 소자 조건에서 안정화 시간이 늘면 MTBF가 증가하고 입력 전이율이나 수신 클록 주파수가 높아지면 감소한다.
- 디지털 시뮬레이션으로는 아날로그 안정화 시간을 재현하기 어려워 CDC 구조와 배치 조건도 확인한다.
