# Buck / Boost / Buck-Boost

> 스위치로 전류 경로를 바꾸고 인덕터에 에너지를 저장·전달해 DC 전압을 변환한다.

## 1. 먼저 구분할 것

| 구조              | 역할                    | 이상적인 CCM 정상상태 전압 관계   |
| --------------- | --------------------- | --------------------- |
| Buck            | 입력보다 낮은 양의 출력         | $V_o=D V_{in}$        |
| Boost           | 입력보다 높은 양의 출력         | $V_o=V_{in}/(1-D)$    |
| 반전형 Buck-Boost  | 입력보다 크거나 작은 크기의 음의 출력 | $V_o=-D V_{in}/(1-D)$ |
| 비반전형 Buck-Boost | 입력보다 높거나 낮은 양의 출력     | 회로·제어 방식에 따라 달라짐      |

$D$는 [[90_Glossary/Circuit/Duty-Cycle|듀티비]]이며 $0<D<1$이다.
위 세 식은 **이상 소자, 정상상태, [[90_Glossary/Circuit/CCM-and-DCM|CCM]]**을 가정한다.
실제 출력은 손실과 제어 동작의 영향을 받는다.

**Buck-Boost라는 이름만으로 출력이 양수인지 음수인지 결정할 수 없다.**
기본 반전형과 4-switch 비반전형을 구분해서 회로도를 읽는다. [전력 변환 구조 개요](https://www.ti.com/video/5219549475001)

## 2. 소자 역할

| 소자 | 동작 |
|---|---|
| 스위치 | ON/OFF로 전류 경로를 선택 |
| 인덕터 L | 자기장에 에너지를 저장하고 전류 변화를 완만하게 함 |
| 다이오드 / 동기 정류 MOSFET | 주 스위치 OFF 때 필요한 전류 경로 제공 |
| 출력 커패시터 C | 충전·방전으로 출력 전압의 변화를 완화 |
| 제어기 | 출력 피드백을 보고 스위칭을 조절 |

$$v_L=L\frac{di_L}{dt},\qquad E_L=\frac12 L i_L^2$$

인덕터 전류는 순간적으로 바뀌지 않는다.
스위치를 꺼도 전류가 흐를 경로가 필요하므로 다이오드나 다른 스위치가 중요하다.
커패시터도 리플을 줄이지만 출력 전압을 완전히 일정하게 만들지는 못한다.

## 3. Buck의 한 주기

기본 비동기 Buck의 연결은 `Vin → 스위치 → SW 노드 → L → Vout`이다.
다이오드는 GND에서 SW 노드로 전류가 흐를 수 있는 방향으로 연결한다.

| 상태 | 인덕터 전류 경로 | 인덕터 전압 | 전류 변화 |
|---|---|---|---|
| ON | Vin → 스위치 → L → 부하 → GND | $V_{in}-V_o$ | 증가 |
| OFF | GND → 다이오드 → L → 부하 → GND | $-V_o$ | 감소 |

OFF여도 인덕터가 부하에 전류를 계속 공급한다.
정상상태에서는 한 주기의 인덕터 전압 평균이 0이므로 다음을 얻는다.

$$(V_{in}-V_o)D+(-V_o)(1-D)=0\quad\Rightarrow\quad V_o=D V_{in}$$

## 4. Boost의 한 주기

기본 비동기 Boost의 연결은 `Vin → L → SW 노드`이고, SW 노드에서 스위치는 GND로, 다이오드는 출력으로 이어진다.

| 상태 | 에너지 이동 | 인덕터 전류 |
|---|---|---|
| ON | Vin → L → 스위치 → GND. 출력 다이오드는 차단되고 C가 부하 공급 | 증가 |
| OFF | Vin과 L이 함께 다이오드를 통해 출력에 에너지 공급 | 감소 |

OFF 때 인덕터 전류를 유지하려고 SW 노드 전압이 올라가 출력으로 전류가 흐른다.
**인덕터가 에너지를 새로 만드는 것은 아니다.**
정상상태 전압 평형은 다음과 같다.

$$V_{in}D+(V_{in}-V_o)(1-D)=0\quad\Rightarrow\quad V_o=\frac{V_{in}}{1-D}$$

전압을 높일수록 같은 출력 전력에 필요한 입력 전류는 커진다.

## 5. 기본 반전형 Buck-Boost

```text
ON : 입력 → 스위치 → 인덕터 → GND
     출력 커패시터가 부하를 공급

OFF: 인덕터의 전압 극성이 바뀜
     다이오드가 도통하며 출력 쪽에 저장 에너지 전달
```

ON 동안 인덕터 전류가 증가하고, OFF 동안 출력으로 에너지가 이동하며 감소한다.
이 회로에서는 공통 GND에 대한 출력 극성이 음수다.

$$V_{in}D+V_o(1-D)=0\quad\Rightarrow\quad V_o=-\frac{D}{1-D}V_{in}$$

예를 들어 이상적인 CCM에서 $V_{in}=5\,V$일 때:

| D | 출력 |
|---|---|
| 0.25 | 약 −1.67 V |
| 0.50 | −5 V |
| 0.75 | −15 V |

이 값은 소자 손실, 최대 전류, 듀티 제한을 무시한 계산이다.
D를 1에 가깝게 한다고 실제 출력이 무한히 증가하지 않는다. [반전형 동작과 수식](https://www.ti.com/lit/an/slva059a/slva059a.pdf)

## 6. 비반전형과의 차이

4-switch 비반전형은 입력·출력 쪽 스위치 브리지 사이에 인덕터를 둔다.
입력이 출력보다 높으면 주로 Buck, 낮으면 주로 Boost 방식으로 제어하며 전환 구간의 제어는 IC에 따라 다르다.

반전형의 $-D/(1-D)$ 식을 그대로 대입하면 안 된다.
스위치 4개의 구동 방식, 출력 극성, 모드 전환 조건을 먼저 확인한다.
[비반전형 구조 설명](https://www.ti.com/de-de/video/5470851944001)

## 7. 파형과 전류를 읽는 방법

```text
스위치  : ON 구간 | OFF 구간 | ON 구간 ...
iL (CCM): 증가    | 감소     | 증가    ...  최솟값 > 0
iL (DCM): 증가    | 0까지 감소 | 0 유지 구간
Vout    : 평균 출력 위에 작은 주기적 Ripple
```

- **CCM/DCM:** 인덕터 전류가 한 주기 내내 이어지는지 구분한다.
- **Ripple:** 출력 평균값과 주기적인 변동 폭을 따로 본다.
- **시동·부하 변동:** 정상상태 수식과 구분한다. 출력 응답은 제어 루프에도 좌우된다.
- **측정:** 스위칭 노드의 빠른 펄스와 출력 커패시터 양단의 리플은 서로 다른 파형이다.

DCM에서는 변환비가 듀티뿐 아니라 부하·인덕턴스·주파수에도 의존한다.
[CCM/DCM 분석](https://www.ti.com/lit/an/slva059a/slva059a.pdf)

## 8. 헷갈리는 부분

| 생각 | 정확한 구분 |
|---|---|
| 스위치를 끄면 전류도 바로 0 | 인덕터 전류를 이어줄 경로로 전류가 이동한다 |
| Boost는 전압과 전류를 모두 증가 | 출력 전력은 입력 전력에서 손실을 뺀 값 |
| Buck-Boost는 모두 음의 출력 | 반전형인지 비반전형인지 구분 |
| 듀티만 정하면 항상 같은 출력 | CCM/DCM, 입력·부하, 손실과 제어 조건이 필요 |

효율을 $\eta$라 두면 평균 전력은 전압·전류 크기를 기준으로 $P_o=\eta P_{in}$이다.
