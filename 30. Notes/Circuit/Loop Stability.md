# 1. 보드 선도와 과도 응답

- 위상 여유는 루프 이득이 0 dB가 되는 주파수에서 위상이 −180°까지 얼마나 남았는지를 나타낸다.
- 이득 여유는 위상이 −180°인 주파수에서 루프 이득을 0 dB까지 얼마나 높일 수 있는지를 나타낸다.
- 감쇠가 작으면 부하가 갑자기 변한 뒤 출력에 오버슈트와 링잉이 나타날 수 있다.
- 주파수 보상은 극점과 영점의 위치를 조절해 응답 속도와 안정 여유를 맞춘다.
