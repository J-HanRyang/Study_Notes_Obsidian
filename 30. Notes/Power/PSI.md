# 1. 현재 이해한 뜻
- 여기서 PSI는 Power Sequence Interface를 가리키며, 대상 제품에서 쓰는 정식 명칭은 제품 명세로 확인한다.
- Main PMIC와 Sub PMIC의 전원 순서를 맞추는 역할로 이해하고 질문했다.
- 실제 제품에서 쓰는 PSI의 정식 의미와 신호 구성은 대상 명세로 확정해야 한다.

# 2. 먼저 확인할 구조
- Main과 Sub 중 어느 쪽이 시퀀스를 시작하는지 확인한다.
- 두 PMIC가 어떤 이벤트에서 다음 상태로 넘어가는지 확인한다.
- PSI가 [[30. Notes/Power/FAULT|FAULT]]와 같은 선을 쓰는지 별도 선을 쓰는지 확인한다.
- PSI가 SPMI 메시지인지 별도 핀 인터페이스인지 블록도와 핀 목록에서 확인한다.

# 3. 읽을 자료의 순서
- 먼저 PMIC 연결도에서 실제 핀과 선을 찾는다.
- 다음으로 Power-up과 Power-down 상태도를 읽는다.
- 마지막으로 시퀀스 타이밍 표와 Fault 발생 시 분기를 대조한다.

# 4. DV에서 확인할 것
- 시작 이벤트마다 Main/Sub PMIC의 기대 상태를 적는다.
- 정상 시작과 중간 Fault를 별도 시나리오로 만든다.
- Reset 이후 시퀀스 재시작 조건을 확인한다.
- 디지털 상태 신호로 확인할 수 있는 범위와 실제 전압 측정이 필요한 범위를 구분한다.

# 5. 아직 확정하지 않은 것
- PSI와 SPMI의 물리적 관계.
- PSI의 신호 극성, 타이밍, 허용 지연.
- Main/Sub 사이 Fault 전달 및 복구 순서.
