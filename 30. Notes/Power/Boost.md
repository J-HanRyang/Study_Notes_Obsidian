# 1. 뜻
- Boost는 입력보다 높은 양의 출력 전압을 만드는 DC-DC 변환 구조다.
- 인덕터에 저장한 에너지를 입력 전원과 함께 출력으로 전달한다.

# 2. 기본 회로
- 기본 비동기 Boost는 `Vin → 인덕터 → SW 노드`로 연결된다.
- SW 노드에서 스위치는 GND 쪽으로, 다이오드는 출력 쪽으로 연결된다.
- 출력 커패시터는 스위치 ON 동안 부하를 공급한다.

# 3. 한 주기의 동작
| 상태 | 에너지 이동 | 인덕터 전류 |
|---|---|---|
| ON | 입력 → 인덕터 → 스위치 → GND | 증가 |
| OFF | 입력과 인덕터 → 다이오드 → 출력 | 감소 |

- ON 동안 출력 다이오드는 차단된다.
- OFF 동안 인덕터 전류를 유지하려고 SW 노드 전압이 올라간다.
- [[90_Glossary/Circuit/CCM|CCM]]의 이상적인 정상상태에서 출력 전압은 $V_o=V_{in}/(1-D)$다.
- $D$는 [[90_Glossary/Circuit/Duty-Cycle|Duty Cycle]]이다.

# 4. 전력과 실제 출력
- 인덕터가 에너지를 새로 만드는 것은 아니다.
- 손실을 무시할 수 없다면 출력 전력은 입력 전력보다 작다.
- 전압을 높일수록 같은 출력 전력에 필요한 입력 전류가 커질 수 있다.
- 듀티를 1에 가깝게 한다고 실제 출력 전압이 무한히 커지지는 않는다.

# 5. 헷갈리는 점
- 스위치 ON 때 인덕터 전류가 증가해도 그 순간 부하를 주로 공급하는 것은 출력 커패시터다.
- [[90_Glossary/Circuit/DCM|DCM]]에서는 CCM 변환비를 그대로 적용하지 않는다.
- 시동·부하 변화와 정상상태 수식을 구분한다.

# 6. 복습
- ON과 OFF에서 출력에 에너지를 공급하는 경로는 각각 무엇인가?
- 전압을 높이면서 입력 전류가 커질 수 있는 이유는 무엇인가?
