# 1. 뜻
- Buck은 입력보다 낮은 양의 출력 전압을 만드는 DC-DC 변환 구조다.
- 스위칭으로 인덕터에 에너지를 저장하고 부하에 전달한다.

# 2. 기본 회로
- 기본 비동기 Buck의 전력 경로는 `Vin → 스위치 → SW 노드 → 인덕터 → Vout`이다.
- 스위치가 꺼진 동안에도 인덕터 전류가 흐를 수 있도록 다이오드 경로가 필요하다.
- 출력 커패시터는 출력 전압의 주기적인 변동을 완화한다.

# 3. 한 주기의 동작
| 상태 | 인덕터 전류 경로 | 인덕터 전압 | 전류 변화 |
|---|---|---|---|
| ON | Vin → 스위치 → 인덕터 → 부하 | $V_{in}-V_o$ | 증가 |
| OFF | GND → 다이오드 → 인덕터 → 부하 | $-V_o$ | 감소 |

- OFF여도 인덕터는 부하에 전류를 계속 공급한다.
- [[90_Glossary/Circuit/CCM|CCM]]의 이상적인 정상상태에서 인덕터 전압의 주기 평균은 0이다.
- 이 조건에서 출력 전압은 $V_o=D V_{in}$이다.
- $D$는 [[90_Glossary/Circuit/Duty-Cycle|Duty Cycle]]이다.

# 4. 파형을 볼 때
- 인덕터 전류가 주기 내내 0보다 크면 CCM이다.
- 인덕터 전류가 0에 도달해 머무는 구간이 있으면 [[90_Glossary/Circuit/DCM|DCM]]이다.
- DCM에서는 출력이 듀티만으로 정해지지 않는다.
- 출력의 [[90_Glossary/Circuit/Ripple|Ripple]]과 시동 과도응답은 구분한다.

# 5. 헷갈리는 점
- 스위치를 끈다고 인덕터 전류가 즉시 0이 되지는 않는다.
- 이상적인 $V_o=D V_{in}$ 식을 손실이 있는 모든 동작에 그대로 적용하지 않는다.
- 부하와 제어 루프가 바뀌면 실제 출력도 달라질 수 있다.

# 6. 복습
- ON과 OFF에서 인덕터 전류 경로를 각각 그릴 수 있는가?
- OFF 때 부하에 에너지를 공급하는 경로를 설명할 수 있는가?
- 같은 듀티에서도 CCM과 DCM의 결과가 달라지는 이유는 무엇인가?
