# 1. 뜻
- Buck-Boost는 입력보다 높거나 낮은 크기의 출력을 얻을 수 있는 DC-DC 변환 구조의 이름이다.
- 이름만 보고 출력의 극성을 정할 수는 없다.
- 반전형과 비반전형의 회로와 제어를 나눠 읽는다.

# 2. 기본 반전형
- ON 동안 인덕터에 에너지가 저장되고 출력 커패시터가 부하를 공급한다.
- OFF 동안 인덕터의 전압 극성이 바뀌고 저장된 에너지가 출력으로 이동한다.
- 공통 GND에 대한 출력 전압의 극성은 음수다.
- 이상적인 [[90_Glossary/Circuit/CCM|CCM]] 정상상태에서는 $V_o=-D V_{in}/(1-D)$다.
- $D$는 [[90_Glossary/Circuit/Duty-Cycle|Duty Cycle]]이다.

| $V_{in}=5\,V$일 때 $D$ | 이상적인 반전형 출력 |
|---|---|
| 0.25 | 약 −1.67 V |
| 0.50 | −5 V |
| 0.75 | −15 V |

- 이 계산은 소자 손실과 최대 전류, 듀티 제한을 무시한다.

# 3. 비반전형
- 4-switch 비반전형은 입력과 출력 쪽 스위치 브리지 사이에 인덕터를 둔다.
- 입력이 출력보다 높으면 Buck, 낮으면 Boost 방식으로 제어할 수 있다.
- 전환 구간의 세부 제어는 사용하는 IC에 따라 달라진다.
- 반전형의 $-D/(1-D)$ 식을 비반전형에 그대로 대입하지 않는다.

# 4. 파형과 조건
- 인덕터 전류의 증가·감소 구간을 스위치 상태와 함께 본다.
- [[90_Glossary/Circuit/DCM|DCM]]에서는 부하와 인덕턴스, 주파수도 변환비에 영향을 준다.
- 출력 [[90_Glossary/Circuit/Ripple|Ripple]]과 시동 Overshoot는 다른 현상이다.
- 효율이 $\eta$이면 평균 전력의 크기는 $P_o=\eta P_{in}$이다.

# 5. 복습
- 현재 회로의 출력이 양수인지 음수인지 먼저 판단할 수 있는가?
- ON과 OFF 동안 인덕터 전류 경로를 그릴 수 있는가?
- CCM 식을 적용할 수 없는 조건을 말할 수 있는가?
